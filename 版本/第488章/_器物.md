# 第488章 · 器物册（造式二代·合稿席立｜照 486、487 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—27行｜拍2=正文31—53行｜拍3=正文57—81行｜拍4=正文85—109行｜拍5=正文113—145行（依次：冰压那一道｜那一层｜後晌与夜｜送那一页｜边上与下坑）。骨记之拍名照胜稿：「拍一」至「拍五」即拍1至拍5。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜七在拍5｜一、二、八至十七通章｜咬合行之拍一在拍1、拍二在拍2、拍四在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行俱含其名（以脚本自正文算出）。
#   ★名与主承同镜前章之册（486 册）：本子、笔、绳、钢尺（尺子）（主=钱满）、匣子、背带（本章白文作「带子」，以之为别名）。本章新入（486 册所无）：灯（老头那盏灯，主=老头；450:105 起挂我腕子上未点，本章拍3 我拿出来递还他）、火柴盒（主=钱满）、碗、听针（白文作「针」，主=钱满）。
#   ★「页头」「新的一页」「今天那一页」「页头一个送字的那一页」「末一行」係本子之部；「笔尖」係笔之部；「绳头」「腰上那一头」係绳之部；「三道」「最上头那一道」「尺头」「那一圈冰」係钢尺与其上之痕、之冰；「闩」「匣子头」「匣子顶」「盖沿底下那道缝」係匣子之部；「那个结」係背带之部；「那一卷油纸」係听针之裹；「那一点火」「火苗」係灯之部；「冰」「冰沿」「泉」「缝口」「水」「水边」「泥」「石头」「石头缝」「土包」「塌下来的那一面」「那一层」「黄土」係场上之设；「气」「水声」「日头」「天」非物；俱不入。
#   ★「裤子」「袖口」「怀」係身上之衣；「手」「左手」「拇指」「拇指甲」「那两根指头」「手背」「手心」「腰」「後腰」「肩」「肩头」「胸口」「膝盖」「脸」「嘴唇」「嘴角」「眼睛」「耳朵」「腿」「脚」「脚脖子」「小腿」係身上之尺；俱不入册。
#   ★前册之物本章白文零名，不入，位照前册：爷爷那把钥匙在我怀里；匣子的盖子合着、绳带勒回，随匣；先人在匣子里，头在当中，眼睛冲着天，右手攥着那一卷血图，随匣；钱满怀里那一摞白文零名。487 她之物（判纸、那一沓、链、手绳、布、刃）二线零进。
#   ★物位交後章：钢尺插在坑里水边泥里，三道露在水上头（→490、491、495）；灯点着，搁在尺子边上（→490、496）；匣子在老头背上，前头两边石头挨到一处那道竖缝跟前往前一倾，刘二从後头扶住（→490）；背带两道上肩三道勒腰，在老头身上；本子揣在我怀里，送那一页末一行一个我字，末一点拖到页边，未描；笔随本子；绳我腰到东头手；听针裹好在钱满怀里；火柴盒在我手里或已回钱满（开口）；碗在泉边刘二手里（零再书）。
