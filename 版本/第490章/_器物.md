# 第490章 · 器物册（造式二代·合稿席立｜照 488、489 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—51行｜拍2=正文55—69行｜拍3=正文73—91行｜拍4=正文95—127行（依次：下到座前｜够一夜吗｜玉入座心｜左掌）。骨记之拍名照胜稿：「拍一」至「拍四」即拍1至拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行俱含其名（以脚本自正文算出；火柴之今格去「火柴盒」所在之行）。
#   ★名与主承同镜前章之册（488 册）：本子、绳、钢尺（尺子）（主=钱满）、匣子、背带（带子）、灯（主=老头）、火柴盒（主=钱满）。本章新入（488 册所无）：玉（主=我；领口那块，480 攥着跟贴着肉一样温的那一块）、火柴（火柴盒里的，本章划两根）。
#   ★「结」「绳头」「腰上那一头」係绳之部；「页头」「今天那一页」係本子之部；「断口」「笔画」係玉之部；「匣子底」係匣子之部；「带子勒过的那一处」係背带勒在刘二肩头之印。
#   ★「领口」「衣裳」「鞋尖」「鞋底」係身上之衣；「手」「右手」「左手」「拇指」「小指头」「指头」「指头梢」「指甲」「掌根」「手心」「手背」「膝盖」「胸口」「胸骨」「後背」「肩头」「脸」「眼睛」「耳朵」「嘴」「气」係身上之尺；「缝」「缝口」「石头」「水」「水边」「坑」「地」「座子」「座沿」「座面」「座心」「窝」「台」係场上之设；「亮」「黄」「黑」「火」「吱」「声音」「数」非物；俱不入册。
#   ★前册之物本章白文零名，不入，位照前册：爷爷那把钥匙在我怀里；笔随本子在我怀里；先人在匣子里，随匣，零名零动；钱满怀里那一摞、听针与油纸俱在其怀；碗在刘二处。老头揣在怀里那只手所攥之物，白文零书，不入。
#   ★物位交後章：玉扣在座心窝里，有笔画的那一面冲下，断口挨上了断口，我的左掌按在它上头（→491、496、500）；钢尺插在缝那头水边泥里，灯搁在它边上点着（→491、495、496）；匣子在老头背上，老头在缝口冲着缝站着，缝里的亮只从匣子四边漏过来（→491、503）；绳从我腰上拖进黑里到东头手里，紧了一下又松了，搭在地上（→503、507）；火柴盒在我手里（496 钱满划火，其回钱满之手须一个递字）；火柴头一根我甩灭，後一根在刘二手里烧到了头。
