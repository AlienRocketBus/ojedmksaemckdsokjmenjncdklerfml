# 第491章 · 器物册（造式二代·合稿席立｜照 489、490 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 7 拍：拍1=正文5—25行｜拍2=正文29—57行｜拍3=正文61—75行｜拍4=正文79—103行｜拍5=正文107—127行｜拍6=正文131—151行｜拍7=正文155—171行（依次：黑里｜群入与头一根火｜够一夜吗｜第二根火｜链头｜缝口空｜灯挑入）。骨记之拍名照胜稿：「拍一」至「拍七」即拍1至拍7。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行以脚本自正文算出。
#   ★名与主承同线前章之册（489 册）：链（链子）（主=他）、布（主=他）、匣子；承 490 册：灯（主=老头）、钢尺（尺子）（主=钱满）、绳（白文作「绳子」）、火柴、玉（490 册作主=我，本章她镜，主照其人书苏衍）。本章新入（前册所无）：锹（白文作「一把锹」）。
#   ★「锹柄」「柄」「柄头」「锹头」「窝」係锹之部；「灯苗」係灯之部；「匣子底」係匣子之部；「布边」係布之部。
#   ★「裤子」「裤腿」「领口」係身上之衣；「膝盖」「腕子」「手」「左手」「右手」「食指」「中指」「指头」「指头肚」「指甲」「指甲盖」「拇指」「小指头」「手背」「腰」「脊梁」「後脑勺」「背」「眼睛」「腿肚子」「胳膊」「头顶」係身上之尺；「坑壁」「印子」「土」「缝」「缝口」「石头」「座子」「台子」「方的那一块」「地」「水」係场上之设；「亮」「黄」「黑」「火」「声音」「数」「嗓子」非物；俱不入册。
#   ★前册之物本章白文零名，不入，位照前册：刃在他後腰；判纸在她右手袖筒；那一沓在她怀里；手绳在她右腕，结零解；火柴盒、本子、笔、钥匙在主线诸人处；一只眼的那一个揣在怀里那只手所攥之物，白文零书（拍7「另一只手还揣在怀里」），不入。
#   ★物位交後章：链从她腰上往後绷直，余头在他拳里，全章一节没响（→492、494、495）；布在他右腕，布边一线白跟平常一样（→496、503）；匣子在方的那一块上（→502、503）；灯挂在锹柄头上，锹头抵在方的那一块根底下、柄斜靠着立住，灯苗直直的（→496、500、502）；锹柄上一个窝冲着上头（→492、504、505）；钢尺留在缝那头水边，暗（→495）；绳从划火的那一个腰上拖进黑里，贴着地（→503、507）；玉在座子当中，那只左手盖在上头（→496、500）；火柴两根俱灭。
