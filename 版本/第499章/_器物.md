# 第499章 · 器物册（造式二代·合稿席立｜照 485、498 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—39行（电台）｜拍2=正文43—59行（纸）｜拍3=正文63—85行（鞭）。骨记之拍名照此：「拍一」即拍1，「拍二」即拍2，「拍三」即拍3。骨记二在拍1｜三在拍2｜四在拍3。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行俱含其名（以脚本自正文算出）。
#   ★名与主承同镜前章 485 之册：镇口那辆车（车）、测绘转上来的那一封（那一封）、今天这一张（本章白文作那一张）、笔、那一卷（卷皮）、热线条子（条子）。本章新入：电台、话筒、付款条（那一卷之头一页，近铺五百零六，故单立）。
#   ★「笔帽」「笔尖」「笔杆」「笔夹子」係笔之部；「钮」「面板」「那一点绿光」係电台之部；「线」「按键」係话筒之部；「头一页」「後头那一页」「卷里的纸」係那一卷之部；「名那一栏」「那一格」「格子的线」「那一角」係付款条之部；「页脚那两枚红章」「横着的一道折痕」「日子那一格」「经手人那一栏」「经手人底下那一栏」「末了那一笔」係那一张之部与痕；「那一道折」「折口」「角」係条子之部；「封角那一块油」係那一封之痕。
#   ★「方向盘」「副座」「仪表台」「钩子」「玻璃」「车灯」「座子」「车底下」「暖风」係车之设；「山」「山脚」「路边」「村子」「天」係场上之设；「鞭」「一挂」「炸了一声」「回过来一声」係场外之声；「沙沙」「嗓子」「喘」「气」「白」非物；「大衣」「大衣襟」「胸口的兜」「兜沿」係身上之衣；「手」「右手」「左手」「拇指」「指甲」「小指头」「食指」「中指」「两根指头」「右腕」「腕子」「胳膊」「肩膀」「眼睛」「胸口」「手背」「筋」「膝盖」係身上之尺；俱不入册。
#   ★前册之物本章白文零名，不入，位照 485 册：车顶灯在车顶上灭着；皮包、电筒在那一处院子屋里柜前；封条压在档柜门缝上，浆子抹在封条背面；档柜、纸条、灶灰在那一处院子。其间三日之迹，白文零书。
#   ★物位交後章：电台、话筒在车里，章末沙沙；那一卷在副座翻开，卷皮叫那一封压住；付款条为其头一页，名那一栏里空着那一格在他右手拇指底下（→506）；那一张推回去在付款条上头，条子在其底下，角盖住了；笔开着在他左手，笔帽在他右手食指跟中指中间（→500）；车停山脚路边，没有熄火。
