# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 6 拍：拍1=正文5—23行｜拍2=正文27—39行｜拍3=正文43—55行｜拍4=正文59—95行｜拍5=正文99—143行｜拍6=正文147—171行（依次：光来｜卡｜贴骨｜绳｜救｜果）。骨记之「拍一」至「拍六」即拍1至拍6。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行以脚本自正文算出。
#   ★名与主承同线前章之册：玉（主=我）、灯（主=老头）、布（主=那人）、锹、绳、火柴照 496 册；手电本章新入，白文零名，别名取「铁的东西」（器验只认这一个）。
#   ★「罩子」係灯之部；「锹柄」係锹之部；「火柴头」係火柴之部；「结」係绳之部；「白」「淡白」「影子」「青」「两点青」「水腥气」「水声」「气」「声音」非物；「座」「座面」「座沿」「座边」「窝」「壁」「石头」「地」「缝」「缝口」「坑」「方的那一块」係场上之设；「衣裳」「袄子」「靴子」係身上之衣；「手」「手心」「手背」「掌」「掌根」「指头」「拇指」「指缝」「拳头」「巴掌」「小臂」「左肘」「肘弯」「肩膀」「脖子」「耳根」「耳朵」「眼睛」「头」「脸」「脑袋」「胸口」「腰」「後腰」「後背」「膝盖」「嘴」「嗓子」「骨头」「肉」係身上之尺；俱不入册。

#   ★物位交後章：玉在我左掌底下座心窝里，烫，挨玉那一圈掌根白了（→500、504、510）；灯挂锹柄头上，罩子里头是黑的（→500）；锹照旧，灯挂柄头（→505）；布在那人右腕两道，我的眼睛离了它（→503、506）；绳随缝里那一个出了缝，零再现，我袄子上留一道勒出来的沟，右手搭在沟上（→503、504）；火柴，钱满那只好手攥拳捏着那一根，拳抵在我後腰上（→500）；手电落在缝里水中，零再现。
