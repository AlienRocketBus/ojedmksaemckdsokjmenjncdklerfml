# 第489章 · 器物册（造式二代·合稿席立｜照 487、488 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—15行｜拍2=正文19—39行｜拍3=正文43—83行（依次：黑里｜过缝｜被读）。骨记之拍名照胜稿：「拍一」至「拍三」即拍1至拍3；咬合行之拍二在拍2、拍三在拍3。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行以脚本自正文算出。
#   ★名与主承同镜前章之册（487 册）：链（本章白文作「链子」，以之为别名）（主=他）、布（主=他）。本章新入（487 册所无）：匣子（名承 488 册）。
#   ★「带子」係匣子之勒（那人背上勒着好几道，承 488:121 两道上肩三道勒腰），本章只拍2 见其名，零动，随匣，不另立行；「木头」係匣子之身。
#   ★拍1「指头肚落在布上」之布係她膝上裤子之布，非此册之布；此册之布係他右腕缠疤那一圈。
#   ★拍3「鼓起来的那一块，布磨得发亮」之布係那人衣襟之布，亦非此册之布；故布之今格去 :7、:43。
#   ★「衣裳」「衣襟」「裤腿」「鞋尖」「袖」係身上之衣；「手」「右手」「左拳」「拇指」「食指」「中指」「指头肚」「指甲缝」「骨节」「腕子」「膝盖」「腰」「背」「肩膀」「胳膊肘」「肋巴骨」「脸」「眼睛」「气」係身上之尺；「坑壁」「缝」「缝口」「石头」「石头棱」「土」「地」係场上之设；「亮」「黄」「黑」「水声」「吱」「响」非物；俱不入册。
#   ★「床头板」「火星」「地上的红」「小影子」係忆中之物（479、477 那两夜），不在场，不入册；「刀那么长」係床头板上那一道白之量，非刀。
#   ★前册之物本章白文零名，不入，位照前册：刃在他後腰，刀把冲上（487:39）；判纸在她右手袖筒，停在小臂（487:97）；那一沓在她怀里，左手按着；手绳在她右腕，结零解。488 之物白文零名：灯（主=老头）点着，搁在缝那头水边尺子边上（488:143），白文只书其亮，零作认物；钢尺（主=钱满）插在水边泥里；本子、笔、绳、火柴盒、碗、听针俱在主线诸人处，二线零进。那人揣在怀里那只手所攥之物，白文零书，不入。
#   ★物位交後章：链从她腰下来，当中一截搁在地上，余头在他左拳，全章一节没响（→491、495）；布缠在他右腕疤上，布底下那一块烫没有下去（→491、496、503）；匣子在那人背上，带子勒着，那人回到缝口冲缝站着，匣子冲着他，亮从匣子四边漏过来（→490）。
