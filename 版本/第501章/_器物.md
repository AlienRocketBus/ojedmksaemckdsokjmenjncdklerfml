# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—27行｜拍2=正文31—45行｜拍3=正文49—61行｜拍4=正文65—95行（依次：紧与松｜也通｜断与那一象｜一口）。骨记之「拍一」至「拍四」即拍1至拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行以脚本自正文算出。
#   ★名与主承同线前章之册：布（主=他）照 497 册（同线「他」之章，上一篇册里有布者即 497；499 册零布，498、500 係异线）。线係本章新入（497—500 四册零载），零主。
