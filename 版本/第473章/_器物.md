# 第473章 · 器物册（造式二代·合稿席立｜照 447、472 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—37行（扬之报；章首卷皮在5）｜拍2=41—53（拆封）｜拍3=57—63（柏冢之报）｜拍4=67—111（一站之报·叫绝；钩在其末 99—111）。骨记三在拍1｜四在拍2｜五在拍3｜六、七在拍4｜一、二、八至十六与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名与主承同镜前章 447 册：「卷皮」「扬字封套（封套）」「章」「印台」「抽屉钥匙（钥匙）」照旧不书主，「笔」主=黎东来；承 431 册：「照抄的那一张（校准那一张）」（447 册作卷皮之部「当头那一页」，本章出卷皮去扬又回，单立）。跨章所比之上一同线章 471（霍钧之镜）册，同名之器零。
#   ★本章新入：「早上那一摞报」「扬那一份（那一份）」（与 447 册「扣押的那一份（那一份）」异物）「柏冢那一份（柏冢那一头的）」「城里那一路的报」「开工单」「热线条子（条子）」「电话（听筒）」（他屋里那一部，与 472 册旅社柜台之电话异物）「出城那一处的册子」。
#   ★「两枚红」「纹路」「黑线头」「石头上的粉」「两点白」係校准那一张之部与痕；「末了那一行」「小眼」「落款」係扬那一份之部；「签」「扬字」「封口」「浆子」「碎渣」係扬字封套之部；「表头」「地方那一格」「会签那一溜」「格子」係开工单之部；「水印子」係柏冢那一份之部；「那两个字」係条子之部；「笔尖」係笔之部；「卡口那一栏」「拦字」「放字」「关上那一栏」係册子之部；「最後一页」「当头那一页」係卷皮之部。
#   ★拍4 听筒里「钥匙在响」「钥匙声断了」係 472 册钥匙串（主=戴套袖那人）之声，物在那一头，零到场，不入；拍4「登记簿上的一行」係热线那边之簿，只在条子来历里，零到场，与 472 册登记簿异物，不入。
#   ★「桌子」「桌沿」「门」「门外头的架子」「楼道」「抽屉」「锁眼」係场上之设，不入（抽屉之钥匙另入）；「大衣」「里兜」「胸口那一层」「腕子」「筋旁边那一道沟」「指肚」「指甲盖」「指头」「手掌」「下巴」「肩膀」係身上之物与其痕，不入册。
