# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—19行（灯与黑）｜拍2=23—53（账·叫绝）｜拍3=57—75（一站）｜拍4=79—85（回城）｜拍5=89—101（封柜）。骨记之拍名照此：「拍一」即拍1，「拍二」即拍2，「拍三」即拍3，「拍四」即拍4，「拍五」即拍5。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜七在拍5｜一、二、八至十五与咬合行通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行俱含其名（以脚本自正文算出）。
