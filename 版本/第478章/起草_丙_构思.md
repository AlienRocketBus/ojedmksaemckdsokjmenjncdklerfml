# 执笔·丙之构思（不说路）

魂（不说路）：前头那条路是给我一个人留的——三个人绕着这一句走了一整天，钱满拿一页账点给我看，我拿一句话把他放开。

进化账所避：①禁字藏复词（473「手心里」藏「心里」）——本章另防「黎明」之黎、「潮湿」「回潮」之潮、「老头儿」；手心一律作手心上，天亮⛔作黎明。②同线隔夜首拍以一物交夜（477）——476 收在日头低、车随前头起步，本章首段以挡风玻璃里头一夜哈气冻成的那一层白交夜，⛔说明句。③嫁名照前章（474 杆子／驾驶室之误）——栏杆、岗亭、驾驶楼、页头空着的那一页照前章原名。④哑者开口前一身动定话头（472）——司机一句、我一句，句前各落一动。

① 读者读完最该记住：拍六「到了那儿，坑你下不下，你自己定。」与其後钱满单手在膝盖上折那一页、塞到最底下、巴掌按住，零一字。托法：全章人言只两句（司机一句在首，我一句在末）；其间四拍人人绕着那件事走——司机不熄火、不看後视镜；我在看得见关口处自己站住（绳一路因东头歇而紧，这一回因我站而松），三看而回；过那辆车我不回头；钱满点两行，眼去窗外一夜不回。静攒满一整章，末拍我开口。其前一拍段九：坑那边一句话筛下一排人（人替人定），翻过来就是我这一句（我不替他定）——⛔叙者连，读者自对。拍二人拦人为第二峰，置前三分之一，给读者往下读之由（过不过得去）。

## 满分之问
- 写法一（线性·岔口起）：车停岔口、司机一句、下车写页头 → 走到看得见关口、站住、三看、回 → 镇口那辆车 → 夜账 → 梦 → 醒、一句、钩。
- 写法二（倒叙·关口起）：首句即站在看得见关口处，栏杆抬一回落一回；再折回早上岔口补车到头；再回关口而返。
- 写法三（夜起）：开篇夜里小店钱满抽账页，关口、镇口那辆车由我望窗时回想填入。
- 比：二首句即险，然折回岔口须一段回叙，说明多於发生；476 末「我往前坐了坐」之接钩被截断，隔夜之物无处落；关口置首则读者未走那一路，绳紧好几回、梁上之雪、东头之坐俱无积，三看失其重。三把人拦人由眼见退为回想，叫绝降格；夜账失白日一路之积，那一页成说明书。一最清、接钩最顺，且首段以司机一句把读者放在险上，关口在前三分之一到，其後那辆车、夜账、梦、一句一拍紧一拍。**取一**，拍一压短，开局即险。

| 二·关口（叫绝） | 往西走；前头老远一个挑担子的；绳一紧是东头又站下，一路好几回（⛔数），後来不回头也站；拐弯看得见了：两道梁往当中一收，收口横栏杆，边上岗亭；我自己站住，胸口那一股从栏杆底下指过去，绳松在雪上（这一回站下的是我）；车开到跟前停稳了栏杆才抬，过去落下（翻 474:67 未停稳即抬）；挑担子的到岗亭跟前，门开了，出来一个人胳膊横在他胸口前头，掏证，那人先看手上一张纸、看脸、又看纸；岗亭的门，一个人开一回（翻 474:67 没有开）；三看答何以不绕：梁上从根白到顶无一个脚印／东头坐在石头上白气出得急／钱满吊着的那只手在袄襟里鼓一块，左手按在上头（翻 474:65 拉袄）；我转身往回走，走过东头身边绳一紧，是我把他拽起 | 绳、栏杆、岗亭的门、证、一张纸、梁上的雪、袄襟 | 岗亭的门，一个人开一回。 |
| 三·镇口那辆车 | 回程踩着来时脚印，朝东的压着朝西的；日头落到背後；镇口那盏灯还没亮，灯底下停着一辆车（呼拍一灯下无人）；满镇雪、墙根、车帮都是黑的，这一辆车门底下溅着一溜黄，干了（439:35·⛔谁的）；车窗蒙白，副驾驶那一扇当中从里头抹开巴掌大一块；离它最近时听得见它底下嗡嗡，火没熄；里头的人没有下来（473:95）；我没有回头 | 那盏灯、车门、一溜黄、车窗那一块 | 里头的人没有下来。 |
| 四·钱满之账 | 镇口头一家，一间屋一张铺，铺头挨窗；那一捆靠门後，柄上那个窝冲着墙（474:31·来历⛔）；东头躺那一头，绳头压在身子底下；屋里吊一个灯泡；夜里那盏灯亮了，车还在；钱满坐靠窗那一头，膝盖挨着我的膝盖，看了好一阵窗外才伸手进怀，拇指捻那一摞，抽一页搁我膝上；一页账：前头日子、当中事由、末了经手人；左食指落头一行「柏冢，随队采访名额，协调」，在采访底下停一停，往回挪到日子上停好一阵；那个日子，爷爷还在（⛔天数⛔算）；下挪一行「补给，油，五罐」，这一行的日子是爷爷进山那一年（以人代年·⛔年）；指头不停日子，挪到经手人一栏，一个字，末一笔往上一挑，挑到头顿出一个小疙瘩（472:65·⛔同一只手⛔书其字），指头停在疙瘩上；钱满的眼睛去窗外灯底下那辆车上，没有回来；那一页他不收回；我的右手搁在旁边不碰 | 账页、左食指、日子、经手人一栏、窗户、灯泡 | 那个日子，爷爷还在。 |
| 五·段九（只象） | 梦里一道坡，坡顶一排人肩挨肩脸冲坡下；坡那边一句话，只一句，调子平，不挑不沉（翻 476:47 一问一答）；那一排人从一头起一个一个往坡下去，下去的没有一个回头；我跟着数；排里一个没动，数到他断了；他出排往另一边走，几步，回过头；这双眼睛没有往他脸上去，落到他脚上：脚停住，脚尖还冲着那一边 | 坡、一排人、那一句、脚 | 这双眼睛没有往他脸上去，落到了他的脚上。 |
| 六·你自己定（叫绝） | 睁眼仍是夜，灯泡灭了，窗外那盏灯亮着；膝上那一页还在，我右手压着它一个角，角叫手心焐热了（醒时不碰，睡里压着）；钱满脸冲窗户，脚尖冲着门，眼睛还在外头；车窗上那一块比天黑时大了一圈；借窗外光掏本子，⛔去页头空着的那一页，往前翻到头一行一个欠字的那一页跟前，拇指压页边，没有翻过去（416:81·余章总案 478 之锚）；揣回；拿起那一页递到他跟前；我说那一句；他没有答；左手拿走，单手在膝盖上折，眼睛没回来，对过去、指甲顺折缝刮一道、再对、再刮，刮到头又刮回来；掀袄襟抽出那一摞半截，塞到最底下，推回去；袄襟掩上，巴掌按在外头 | 账页、灯泡、本子、欠字那一页、钱满的脚、袄襟、那一摞 | 「到了那儿，坑你下不下，你自己定。」 |

③ 易写平、写俗、写成前章样子之处，各出今天之样：页头（476 笔尖在六字後停）→今岔口站着写，左手离结托本子，写罢扳六下｜司机（476 下车看路熄火三字）→今不熄火、眼不往後视镜去（翻 474:69），一句｜绳（476 睡时绷坐直松）→今一路因东头站下而紧，关前因我站下而松，回时我拽起他，夜里压在他身子底下｜栏杆、岗亭的门→474 自抬、没有开，今停稳才抬、一个人开一回｜袄襟（474 拉袄盖吊带）→今已盖着，鼓一块，左手按住｜白（476 车队屁股後头的白）→今那辆车窗里头蒙的白，抹开一块，比天黑时大了一圈，呼本章首段一驾驶楼哈了一夜的气｜梦（476 字一个也听不出）→今⛔说听不听得出，只说调子平｜醒（476 先觉身上不拽）→今先见膝上那一页还在｜收→⛔照段案钩句，钱满单手在膝盖上折、指甲刮缝为全章最长之静。
④ 收句：「袄襟掩上了。他左手的巴掌按在外头，按着那一摞。」——事收在他手上：坑下不下他一个字没有，收在一只按着的手上；⛔照段案原句；⛔落在那辆车上（车交 480、484）；⛔收在我身上（我那一句已说完，再写我即是补）。
⑤ 第二件咬进来：无第二事。咬进来者皆出「前头之路由人拦、拦的人跟着」一事，来处亲印：474:67「车还没有停稳，栏杆自己抬起来了。岗亭的门，这一回没有开。」→拍二｜474:65「前头，钱满拿左手把袄往吊着的那只胳膊上拉了拉。」→拍二｜472:61「同行一人右臂吊带」→拍二那一张纸读者自合｜473:111「关上那一栏，笔尖悬了一下，落了。」→拍二人拦人｜472:65「走到末了那一笔，它往上一挑，挑到头，拇指底下鼓着一个小疙瘩。」→拍四｜474:31「那一捆我上了肩，柄上那个窝冲着我。」→拍四｜416:81「页头那一行空着，头一行一个字：欠。」→拍六。
当场之裁：①两枚章改挂 485——412 量出小一线的是钱满右手拇指甲，那只手今吊着，页上只一枚，我凭眼看不出小一线，硬添一量则点两行之手分去第三处、夜账之重散。②柏冢之日作「爷爷还在」——正文「爷爷动身」零见（grep 零中），「还在」於走、於死两读俱实。③补给一行之日作「爷爷进山那一年」——读者凭此知是当年之账、经手人不是今人，父子一脉自合，⛔同一只手。④余章总案点到本章梦中另一象并梦页补字，此稿梦只照段案段九，交总编辑（主会话）裁，倾向挪後章。⑤钱满零句，余章总案旧载本章钱满一问，从开镜卡「钱满零答」。
厚：估净重二千五上下，低於段案参考带——六拍是一事之六面，人言两句，余在路上与手上；此章之重在静，静写满即止，再长即撒感官；近十章净重二千一至二千六，同线 476 二千三，⛔凑。
