# 第431章 · 器物册（造式二代·合稿席立｜照 423、427、430 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—25行（归卷与一纸一程）｜拍2=29—53（回执）｜拍3=57—97（院）｜拍4=101—113（车里）。骨记三、四在拍1｜五、六在拍2｜七至十在拍3｜十一、十二在拍4｜一、二、十三至十五与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 423 册与 427 册：「照抄的那一张」（423 册之今天这一张，今白文作「校准那一张」）、「会签单」「签收（黄的那一张）」「底稿」「公文包（包）」主=黎东来，照 423 册；「档柜（柜子）」「砚（砚台）」主=霍钧、「柴」主=霍钧，照 427 册。
#   ★423 册「笔」本章白文零名（填格、签、添一行俱不出其字），照 423 末位在他身上，不入册；「纸条（那一条）」「章匣（匣子）」「匣里那一样」「那一册」本章零见（柜不开；章匣随霍钧东去），不入册。
#   ★「浆子」係封皮、封条之部；「签」「封口」係封套之部；「格」「栏」「行」「字」「名字」「那一圈红」係诸纸之部与痕；「横棱」係大脚窝之痕；「门扣」「门缝」係柜之部。
#   ★「院门」「屋门」「门槛」「隔壁那一间」「案」「椅子」「床」「被子」「灶」「灶口」「旮旯」「架子」「抽屉」「窗格子」「过道」「水磨石」「楼梯」「巷子」「後墙」「路」「霜」「泥」「碎叶子」「脚窝」係场上之设与迹，不入册；「大衣」「兜」「指肚」「手掌」「食指」「後跟」「鞋底」「眼睛」係身上之物，不入册（铁掌例外：叫绝凭它，入册）。
