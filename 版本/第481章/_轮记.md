# 第481章 · 轮记

- 本章之一事（开镜卡问三，抄）：押解路上车又停在一处邮电门口，她从襟上那一沓里抽出一张折好的纸，投进门边那个绿铁筒子；他看见了纸上露出的那一行（第一百八十五日，他还在），没有拦，左拳里的链子放出去一截，正够她的手到那道扁口子（余章总案:117；479 门边铁筒子之用由此交）。
- **翻掉了什么**（以下五问，记席据盘上正文＝v01 作答·1124）：押她的人那只拳头。479 他攥链只防她走（479:53 链溜出一截又攥上、479:87 没有紧也没有松），本章夜里她一动他还攥紧（:51），天亮却松开一点、放出一截黑的让她的拇指够着扁口子（:91—95），末了「链子在他拳头里，没有紧」（:105）。一并翻掉：479:93「她的头没有往这边偏」→:45「她的脸往他这边偏过来了」；479:7「指节是白的」→:103「指节没有白」；478:39 停稳即抬杆→:15「栏杆没有起来」。
- **事摆完了没有**：摆完了。关口（:5—35：栏杆不起、下摆盖链、纸从他胸前过去挨她的脸、两只手不动）｜一夜（:39—55：铁筒子齐车窗、链一响拳一紧、霜到拳头为止）｜投邮（:59—105：展纸一行、他读两回、胳膊过胸、摇窗、白断、放一截黑的、筒里一响、白出、低了一点）｜一站一报（:109—115：牌子与表、小本一行、看链看窗不言、窗不摇）。四拍各有物作证；信寄给谁、开车的替谁记、她认出了谁，是留给 507、483、484 之钩，⛔在本章说破。
- **哪一样是别处来的**：「又冒出来一点绿」承 479:93；关口之梁、栏杆、岗亭、举到脸边上之纸承 478:37—43；「停稳了」翻 478:39；「第一百八十五日，他还在。」承 385:89 同式与 467 末见东头（暗185）；铁筒子与「扁口子下沿那一溜亮」承 479:73、479:85；「指节没有白」翻 479:7；「他嘴上的白」承 479:11；「没有紧」承 479:87；开车的候邮电承 435:5、439。
- **还有哪一层是我知道、却没写进去的**：①那个「他」是东头——他的亲弟弟（骨记二），叙者零说，车里无人开口，读者凭 385:89 同式自合；②信寄给谁——青溪粮房老周收、给阿禾（余章总案:119），信面外头那一面冲着她自己（:75），零入白文；③她在协查纸上认出的是谁（:27）——留 484；④开车的小本记给谁（:113）——留 483；⑤他为何放——零心语，只由眼路（:71—75）与一松一攥（:91、:95）交；⑥押她的人是那一夜火里的人，他胸前过去一封报平安的信——骨记五末，此句零书。
- **若只留一样**：留 :93「链子从拳头里出去一截。出去的那一截是黑的，上头没有白。」——它一句把一夜之霜（:53）变成尺，把他攥了一路的拳头变成给，零数零心语。
- **承前之判**（同线前章 479 收句之骨逐样落判·记席 1124）：「一点绿」——**认**：:5「前头路边，又冒出来一点绿」接镜里退没的那一点，彼句零照抄；「小镜子」——**搁下**：本章零镜（段案⛔镜收），窗外之事只从那一截窗见（:111）；「她的头没有往这边偏」——**翻**：:45「她的脸往他这边偏过来了，眼睛越过他，落在窗外头」；「镜子里落着日头」——**认**而翻作日头在前：:7「日头早转到前头去了，正冲着车头」；479:87「没有紧，也没有松」——**认**而去半句：:105「链子在他拳头里，没有紧」。

## 造式·盲读

- 读到发生了什么：车过山口岗亭查人，他用大衣下摆盖住链子混了过去；夜里停在山脚一处小邮电门前过夜；清早她当着他的面从那一沓里抽出一张写着「第一百八十五日，他还在。」的纸，探身摇下他那边的车窗，塞进了门口的邮筒，他松开一截链子让她够着；开车的回车上在小本子上记了一行，看了看链子和那截窗，才开车。
- 读不懂处：全懂
- 读错处：1. 第479章「座是一条长的，她在当中，他挨着门」。我一直当车里只有他们俩，直到「她那边的车门开了……座子一轻」才反应过来她另一边还坐着开车的。第481章写明了「开车的」，回看才对上。
2. 第479章火场回忆里的孩子，读着以为只是他的往事；读到「那只左手松着，拇指搭在中指的指甲上，当中是空的」和「她右手的腕子上，那个结湿着」，才觉得那孩子可能就是如今的她（右腕、拇指压在中指的指甲上，两处对得上）。到现在也拿不准是她，还是他把她当成了那个孩子。
3. 第481章的信「第一百八十五日，他还在。」第一眼我以为「他」是身边这个男人，是她报信；又想到第480章页头写的是「第一百九十八天」，这信也可能是早写好的，或者是另一套记日子的法子。「他」指谁，至今没定。
4. 第480章开头读了几行，才确认叙述的「我」不是第479章的他。
- 最记得：「他的拳头松开了一点。链子从拳头里出去一截。出去的那一截是黑的，上头没有白。」他攥了一夜的那截链子是黑的，座上的都结了白。他这一松，等于默许她寄信，一个字也没说。
- 前情之指：1. 「她右腕上那个结」「收头剩下的那一截绳头」：结是谁系的、有什么意思，猜是某种封或者誓。
2. 「链子……到她腰上去」：为什么两人锁在一起，猜是押送或看守。
3. 「那一沓」「按着那一沓」：她襟里的一沓纸，第481章露出是信或纸条，来历不明。
4. 「右胳膊横在膝盖上，压着那一方」：一方什么，猜是手帕或布包。
5. 「拇指正落在铜上那一笔上」「鞘口那一圈铜……那一笔斜着」：刀鞘上刻的一笔，猜是记号或字的一笔。
6. 「他自己身上那道疤」「一句话从骨头里来了」：疤和那句话都无出处，猜是这把刀和这场火留下的。
7. 「钱满」「东头」「绳头攥在手里」：第480章的同伴，「东头」的绳头是什么不知道。
8. 「那一卷的结」「写那一卷」：我怀里的一卷，猜是卷轴或图。
9. 「那块玉」：我领口里的玉。
10. 「拔根那一行」：本子上的旧条目，猜是某种术或事件的名目。
11. 「尺子」「三道」「他那两道……我那一道」：钢尺上的刻痕，猜是三人各刻一道作记号。
12. 「三溜」「页边上那个一」「三个钟点碰在一处」：本子上三栏按日排的数，猜是三样东西的时刻在对齐、倒计时。
13. 「这一回没有罐子」：窗台外原先有罐子，猜是有人每天放的。
14. 「出城那一根……关口那一根，我没有写」：两根栏杆，前情里的路程。
15. 「身上那一股，它从窗户那边指出去」：身上一股指方向的感应。
16. 「那一包，从柜台後头拿出来的时候还冒着热气」：猜是吃的。
17. 「第一百九十八天」「第一百八十五日」：两套记日子，起点不明。
18. 「比昨天大了」那道山、「麦秸」：前一夜睡在麦草里，前情。

### 读误之判

misread＝否。盲读者所得之事（关口盖链、邮电一夜、投信放链、开车的记本）与开镜卡问三之一事全合；全员之账无一相抵。读错 1、4 属 479、480 且已由 481:47、:59「开车的」自销；读错 2（那孩子即她）合 479 亮点「由读者自合」之设计，读者正往对处去；读错 3（「他」指谁未定）係段案守②「东头之去处与由⛔说破」之设计，读者并未定错（「至今没定」），全书读者凭 385:89 同式与 467:109 自合。无须加动作。
