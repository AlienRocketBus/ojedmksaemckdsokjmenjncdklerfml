# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—39行｜拍2=正文43—99行｜拍3=正文103—119行｜拍4=正文123—143行（依次：灯下｜见｜肘｜迟报）。骨记之拍名照胜稿：「拍一」至「拍四」即拍1至拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行以脚本自正文算出。
#   ★名与主承同线前章之册：灯（主=老头）、锹、绳、匣子承 491 册；玉（主=我）照同线前章 490 册（491 她镜作「主=苏衍」，器验以同线为准）；链（链子）、布承 491 册，其主照本镜书「那人」（491 册她镜作「他」）。本章新入（前册所无）：零。
#   ★「灯苗」「灯襻」係灯之部；「锹柄」「柄」「窝」係锹之部；「布边」係布之部。
#   ★「靴尖」「裤腿」「裤脚」「领口」係身上之衣；「手」「左手」「右手」「左拳」「拳」「食指」「指头」「指甲」「指甲盖」「指节」「掌根」「手心」「手背」「肘」「左肘」「小臂」「胳膊肘」「胳膊」「肩膀」「左肩」「眼睛」「眼珠」「膝盖」「腿」「腿肚子」「脚脖子」「下巴」「鼻梁」「眉骨」「头顶」「腰」係身上之尺；「座」「座子」「座沿」「台子」「长的那一块」「方的那一块」「坑壁」「壁」「壁根」「石环」「环」「石头」「印子」「土」「缝」「地」「水」係场上之设；「亮」「黑」「影子」「数」「响」非物；俱不入册。
