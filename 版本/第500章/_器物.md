# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—39行｜拍2=正文43—69行｜拍3=正文73—115行｜拍4=正文119—137行｜拍5=正文141—165行（依次：掉头｜一股一股｜末一股｜凉｜火）。骨记之「拍一」至「拍五」即拍1至拍5。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行以脚本自正文算出。
#   ★名与主承同线前章 498 之册：玉（主=我）、灯（主=老头）、锹、火柴照 498 册；火柴盒照 498 册「前册之物」之名，白文作盒子，别名取「盒子」（器验只认这一个）。
#   ★「罩子」「灯芯」「灯苗」係灯之部；「锹柄」「柄头」係锹之部；「抽屉」係火柴盒之部；「火柴头」「火苗」係火柴之部；「鞭」「水声」「靴子」「人声」係场外之声；「青」「两点青」「青白」「亮」「那一点亮」「那一层」「那几股」「声音」「气声」「白」「那一圈白」非物；「座」「座底」「座子」「窝」「壁根」「地」「石头」「缝」「缝口」「坑」「方的那一块」「大的那一块」「小的那一块」係场上之设；「袄子」「衣裳」係身上之衣，「腰上那道沟」係袄子上之痕；「手」「手心」「掌」「掌根」「指头」「小指」「拳头」「巴掌」「胳膊」「肘弯」「肩膀」「耳根」「耳朵」「眼睛」「头顶」「脸」「膝盖」「腰」「後腰」「腰眼」「骨头」係身上之尺；俱不入册。
