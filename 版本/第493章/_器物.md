# 第493章 · 器物册（造式二代·合稿席立｜照 489、491、492 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—25行｜拍2=正文29—57行｜拍3=正文61—83行｜拍4=正文87—103行（依次：亮到｜众手｜她与一只眼的｜疤）。骨记之拍名照合稿：「拍一」至「拍四」即拍1至拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行以脚本自正文算出。
#   ★名与主承同线前章之册（491 册）：链（链子）（主=他）、布（主=他）、匣子、灯（主=老头）、绳；承 488 册：听针（针）（主=钱满）。本章新入（前册所无）：钱满那一册（册子）（主=钱满；本名另立，以别她那本「册子」——318—395 册俱作「册子」主=她，⛔混作一物）。
#   ★「布头」係布之部；「匣沿」「帮」「棱」係匣子之部，拍4 白文只见「匣沿」（一只眼的那只手已经从匣沿上下来了），器验只认「匣子」，故匣子之出=3，其下匣沿之事记在去处；「灯苗」係灯之部；「油纸」「那一卷」「纸角」「针尖」係听针之裹与其部（照 488 册「那一卷油纸」係听针之裹）；「册子的皮」「一页的角」係钱满那一册之部；「环」「石环」係场上之设（照 492 册）。
#   ★拍3「是攥着带子攥久了」之带子係他读那只手所见之旧迹，非在场之物，随匣，不另立行。
#   ★「靴尖」「靴面」「裤腿」「衣襟」「衣裳」係身上之衣；「手」「左手」「右手」「拳头」「指头」「指头尖」「指头肚」「指头根」「指甲盖」「拇指」「食指」「虎口」「掌根」「手掌」「手心」「手背」「腕子」「小臂」「胳膊」「右胳膊」「胳膊肘」「肋巴骨」「胸口」「膝头」「膝盖」「脚脖子」「小腿」「骨节」「青筋」「皮」「肉」「骨头」「嘴」「牙」「头」「耳朵」「眼睛」「气」係身上之尺；「座子」「座沿」「台子」「坑」「壁根」「缝口」「缝」「地」「石头」「纹路」係场上之设；「亮」「黑」「红印子」「印子」「红」「白」「数」「水声」「响」非物；俱不入册。
#   ★前册之物本章白文零名，不入，位照前册：锹斜靠方的那一块，灯挂柄上（→505）；玉在座心窝，那孩子左掌按其上（→496）；刃在他後腰（→494）；判纸在她右手袖筒、那一沓在她怀里、手绳在她右腕（→495）；钢尺留在缝那头水边，暗（→495）；火柴盒、本子在那孩子身上（→496）；一只眼的那一个揣在怀里那只手所攥之物，白文零书（拍3「另一只在怀里。衣襟底下还鼓着那一块。」），不入（→494、503）。
#   ★物位交後章：链在壁根石环上两道还勒着，往那孩子那边直，往他这边富余，她过得到他的靴尖跟前（→494）；布在他右腕两道，末头掖底，左手心隔布按过，烫下去了（→496、503）；匣子在方的那一块上，扶匣那两只手离开，空着手心冲上没有放下去，一只眼的那只手搭上匣沿又下来了（→502）；灯挂锹柄，灯苗直直的（→496）；绳那孩子腰上到缝口两只手里，松着，左手在前右手在後隔一拃（→503、507）；听针裹回油纸卷紧揣进钱满怀里（→504）；钱满那一册（册子）在他膝盖上没有收，一页的角折着冲外（→506）。
