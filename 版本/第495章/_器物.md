# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。

#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行以脚本自正文算出。
#   ★名与主承前册：链（链子）（主=他·照同线前章 493 册之称，即壁根那一个；494 主线册书那人，同一人，器验以同线前章为准）、锁、绳、刃（刀）（主=她）、鞘（主=她）照 494 册；那一沓（主=她）、铅笔头（主=她）照 487、471 册；钢尺（尺子）（主=钱满）照 491、490 册。本章新入：今天那一张（这一张）（主=她·自那一沓捻出之一张白的，记这一日，折成小方块；⛔并入那一沓，⛔与 485 册之「今天这一张」相混）。
#   ★「刀把」「刀尖」「刀口」係刃之部；「鞘口」「那一圈铜」「铜上斜着的那一笔」係鞘之部；「锁梁」係锁之部；「旧纸」「写过的」「白的」係那一沓之部；「笔尖」係铅笔头之部；「纸」「小方块」係今天那一张之称（器验只认这一张）；「座子」「座」「环」「石环」「壁根」「台沿」「缝」「缝口」「方的那一块」係场上之设；「襟」「靴尖」係身上之衣；「亮」「影子」「水声」「土」「湿」「印子」非物，「水里那一盏」係灯之倒影、非物；「两样」「那一样」係刃与鞘之代称；「手」「手心」「指头」「指头尖」「食指」「拇指」「拇指甲」「指甲盖」「拳头」「胳膊」「肘弯」「肩膀」「肋巴骨」「膝盖」「大腿」「脚尖」「脚心」「腰」「脸」「下巴」「脖子」「嗓子」「眼睛」係身上之尺；俱不入册。
