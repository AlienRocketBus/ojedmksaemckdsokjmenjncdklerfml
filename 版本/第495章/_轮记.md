# 第495章 · 轮记

本章之一事：她站在链子到头三步之外，问了一回「还有几息？」，他照报给钱满的声口报「九」；她记下这一日，数到八，用那把刀自己动手，留下两句话。

## 造式·盲读

读到发生了什么「她被链子拴着，离伸手的那孩子还差三步过不去。她问「还有几息」，有人答「九」。她在纸上写下当天的日子和「他还在」，用刀把数着息，到「八」时地底震动，她趁势把刀对准自己刺了进去，跪倒，对那孩子说「我们本来说好了的」，又回头冲那人说「这一次，是我自己选的」，泪流满面。」｜读不懂处「1. 「九。」是谁说的，没交代。上一句是「那孩子的眼睛下去了，落在座子上。」中间又隔了一句「隔了一阵。刀把上那根食指起来，落下去，又起来。」我回头才猜是那孩子看着座子报的，因为493有「那孩子报过那个数以後」，但这一章本身没落实，也可能是钱满。
2. 「落到了往常拇指要按下去的那一处，拇指起来了……没有按……地底下上来了一阵……拇指按了下去。是八。」她用食指落、拇指按来数息，这套数法我读两遍才拼出来：拇指按一下就是一息，地底那一阵来，才算过了一息。可是「九」到「八」之间食指落了好一阵，一息这么长？「息」到底是什么的单位，我到读完也不确定，只知道是在倒数。
3. 「她在那一阵里，把刀尖调过来，冲着自己，往里一送。」动作看得懂，可她为什么要在这一刻对自己下手、对谁有用，这三章里找不出因果。494老头喊的是「割绳！往苏衍那边去！」，她也照做走过来了，到495却变成自刺。前后之间的逻辑断了，只能靠「这一次，是我自己选的」去硬接。另外刺中之后不写血也不写疼，只写「脸上是湿的」，我拿不准她伤得多重、是不是要死了。
4. 493里「烫是从当中起的……骨头里，什么也没有响」，那人按着腕子听骨头，听的是什么，本章没交代清楚。」｜读错处「1. 495「脸上是湿的。湿到下巴底下，顺着脖子，进了襟里。」我先以为是刀口的血往上返，后来才读成眼泪，到现在仍拿不准，因为自刺以后一个血字也没有。
2. 494「我」是谁，我一开始以为是钱满，读到「钱满在我旁边」和「往苏衍那边去」，她又朝「我」走过来，才确定「我」是那孩子苏衍。493、495的「那孩子」也是他，三章的视角是轮着换的（493那人、494苏衍、495她），换的时候我都卡了一下。
3. 「九」我先当成那孩子报的，后来想到也可能是钱满，至今拿不准。」｜最记得「「她在那一阵里，把刀尖调过来，冲着自己，往里一送。刀口上那一线亮，不见了。」还有前面写纸那一拍：「写到日字，後头点了一点，又写了三个字。他还在。」」｜前情之指「1. 「铅笔头」「那一沓，旧纸」「写过的在上头，白的在底下」「先写这一日」：她一直有逐日记录的习惯，回指前文。
2. 「鞘口那一圈铜……铜上斜着的那一笔」：刀鞘上的一道刻痕，大概是她或别人从前刻的记号。
3. 「锁梁穿着的那一节上，两道白」：锁或链上的磨痕或刻痕，前情。
4. 「竖在那一头水边的那把尺子」「水里那一盏」：缝那头量水位的尺和水里的灯，前情布置。

## 造式·盲读·第2回（回写之後复验）

读到发生了什么：她被链子拴着，站在离那孩子三步的地方，问还有几息；那孩子答「九」以後，她在纸上写下这一日和「他还在」，叠好揣起来；等地底那一阵上来、拇指按到「八」，她掉转刀尖刺向自己，跪下来对那孩子说「我们本来说好了的」，又回头对拴着她的那人说「这一次，是我自己选的」，脸上全是泪。

读不懂处：1）「拇指按了下去。／是八。」——读到这儿得回头把「落到了往常拇指要按下去的那一处，拇指起来了……没有按」再读一遍。我猜她是拿食指数息、数到一个数就用拇指按一下，可「九」说出口以後，「是八」到底指什么，我拿不准：是过了一息、还剩八？是地底那一阵来得比九早、才到八就来了？还是这一阵本身就叫「八」？这一拍是全章的扳机，偏偏这里最含糊。2）「她在那一阵里，把刀尖调过来，冲着自己，往里一送。刀口上那一线亮，不见了。」——我读了两遍才敢认定她是捅了自己：没有血，没有疼，没写刀进了哪里，下一句就是「膝盖先着了地」，接着还能说两句整话、眨眼、流泪。「往里一送」「亮不见了」也可以读成回鞘，可鞘明明在她左手里（「左手里那一样，还攥着」）。到底是自尽、是伤，还是别的，读完我仍是靠推断，不是看到的。3）「腰上那条链子跟着松了」——是因为她跪下去、往前的劲没了才松，还是她一死链子（锁）有了什么变化？只读得出松，读不出为什么。

读错处：1）「刀尖调过来，冲着自己，往里一送」：头一回我读成她把刀收回鞘里（「亮不见了」），往下读到鞘还攥在左手、右手空着落在膝盖上，才改成刺进自己身子——到现在也只有七成把握。2）「他还在。」：起先当是写那孩子（她眼睛刚看过他的手心），後来因为末了她回头对那人说「这一次，是我自己选的」，又疑心是写那人；至今拿不准「他」是谁。3）494 的「老头揣在怀里的那只手，出来了」：我先以为他要掏家伙，结果是扑人，怀里那一块还鼓着——这个不算错读，只是那块鼓着的到底是什么，三章里一直没揭。

最记得：「她写在当中，先写这一日。写到日字，後头点了一点，又写了三个字。／他还在。／三个字跟前头那几个一般大，一笔也没有歪。」
