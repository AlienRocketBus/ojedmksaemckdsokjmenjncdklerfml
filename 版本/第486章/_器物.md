# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）

#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。今格之行俱含其名（以脚本自正文算出）。

#   ★「页头」「新的一页」「画着九个点的那一页」「写着十九、十八的那一页」「三溜那一页」係本子之部；「笔尖」係笔之部；「绳头」係绳之部；「三道」「最上头那一道」係钢尺上之痕；「横档」「槽」「刀口」「齿口」係闩与钥匙之部；「盖沿」「盖沿底下那道缝」「匣子帮」「匣子头」「匣子脚」「那一块板」係匣子之部；「结」「最後那个结」係绳带之部；「颈子底下的布」係先人身下之布；「土包」「柏树」「黄土」「泉」「石头缝」「缝口」「冰」「冰圈」「冰沿」「泥」「柏树尖」係场上之设；「日头」「水声」「冻」非物；俱不入。
#   ★「袄」「衣裳」「怀」「胸口」係身上之衣；「手」「左手」「右手」「食指」「拇指」「两根指头」「指甲」「指头肚」「手背」「手心」「腰」「肩头」「脸」「嘴唇」「眼睛」「背」「腿」「脚底板」係身上之尺；俱不入册。钱满怀里那一摞白文零名，不入，位照前册。
